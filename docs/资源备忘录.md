## 本次经验沉淀

- 对于毕业论文修改任务，除了记录结论，还要记录**参考资源路径**与**源码入口路径**，这样下次继续修改时不用重新定位。
- 对标优质论文时，最值得优先记录的是：`参考 PDF`、`提取文本`、`当前论文主文件`、`原项目地址`、`原项目链接`。
- **ToB 物流平台术语收敛**是系统性工作，需同时修改前端页面、网关权限和论文。建议用 `sed` 批量替换中文文本，但必须跳过 API 路径和数据库字段名等代码标识符。
- 论文中描述系统功能时必须与前端实际展示一致，否则答辩截图会露馅。每次改前端后同步更新论文对应段落。
- **AIGC 风格去痕**四字诀：拆模板、换句式、删冗余、加数据。核心是打破工整对称和句式重复。
  - "通过X实现Y"是 AIGC 最常见的句式，需换成"借助X完成Y"、"X驱动Y"、"X负责Y"等
  - 章节开头不要每章都用"首先...然后...最后"，改用自然的过渡方式
  - "旨在"=公文式AIGC标志，直接删除或换"目标是"
  - 无数据支撑的"显著/有效"一律删除，有数据的才保留
