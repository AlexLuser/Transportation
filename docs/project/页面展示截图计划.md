## 四、截图通用规范

1. **浏览器视口**：1920×1080（或 1440×900），确保 Element Plus 表格与地图完整展示
2. **截图前准备**：
   - 确保浏览器 DevTools 关闭
   - 确保无弹窗遮挡
   - 地图页面需等待 Leaflet 瓦片加载完成（约 2-3 秒）
3. **拼接原则**：
   - 若一张图包含两个页面（如登录+注册、Dashboard+审核），用纵向拼接，中间留 20px 间距
   - 拼接后总高度不宜超过 3000px，避免论文中图片过小
4. **文件命名**：与论文引用完全一致，输出到 `thesis-typst/template/figures/` 覆盖旧图
5. **文件格式**：PNG，保持清晰
